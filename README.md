# Random
Programa gerado como aprendizado em desenvolver aplicações usando Inteligência Artificial.
Este programa altera as configurações de rede da placa Ethernet e configuração de Proxy.
Visa ambientes em que a atribuição do IP, configuração da rede deve ser feita manualmente, sem DHCP.
É necessário direitos de Administrador no sistema operacional, devendo ser Windows 10 ou superior.
A personalização do programa pode ser realizada editando o arquivo .ps1 que será adicionado posteriormente ao repositório.
